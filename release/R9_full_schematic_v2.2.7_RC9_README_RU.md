# RADAR D79 24 В. Полный комплект схем v2.2.7 RC9

Комплект содержит нативные исходники Altium, полную многостраничную PDF-схему, одностраничный мастер-лист с межлистовыми электрическими цепями, таблицу привязки контактов и актуальную плату R9.

## Основные файлы

1. `01_Схема_Altium/RADAR_D79_24V_R9.PrjPcb` содержит основной проект из обзорного и 31 элементного листа.
2. `02_Мастер_лист_Altium/RADAR_D79_24V_R9_FULL_ELEMENT.PrjPcb` содержит отдельный проект полной элементной схемы на одном расширенном листе.
3. `02_Мастер_лист_Altium/00_FULL_ELEMENT_SCHEMATIC.SchDoc` содержит 3 497 примитивов исходных листов, 145 межлистовых проводников и 145 меток цепей Altium.
4. `02_Мастер_лист_Altium/R9_master_inter_sheet_connectivity.csv` содержит точные имена 145 межлистовых цепей и номера связанных листов.
5. `04_Проверка/R9_pad_binding.csv` содержит 1 408 строк `Designator`, `Pad`, `Net` для проверки и повторной трассировки платы. Цепи назначены 1 181 контакту, ещё 227 контактов отмечены как неподключённые.
6. `03_PDF/RADAR_D79_R9_FULL_ELEMENT_MASTER.pdf` содержит одностраничную векторную схему и матрицу межлистовых соединений.
7. `03_PDF/RADAR_D79_R9_full_schematic.pdf` содержит обзорный лист и 31 подробный лист.
8. `03_PDF/Антенный_узел_радара_D79_v0.8.0_R9.pdf` содержит отдельное представление круглого антенного узла.
9. `05_Плата/RADAR_D79_POWER_24V_v0.8.0_R9_NATIVE.PcbDoc` содержит нативную плату для размещения, задания правил, трассировки и DRC.

## Данные для повторной трассировки

Для восстановления соединений используют три согласованных представления:

- нативные `SchDoc` с компонентами, выводами, локальными проводниками, обозначениями и номиналами;
- таблицу межлистовых цепей с точными именами и номерами листов;
- таблицу привязки каждого контакта компонента к цепи платы.

Одностраничный мастер предназначен для поиска маршрута цепи между функциональными узлами. Детальную проверку выводов выполняют по исходным `SchDoc` и `R9_pad_binding.csv`. Новую трассировку выполняют в нативном `PcbDoc` с повторной проверкой классов цепей, правил зазоров, контролируемого импеданса, возвратных токов, DRC и целостности соединений.

## ВЧ тракт и антенны

На мастер-листе показан AWR2944P и восемь ВЧ каналов:

- TX1, TI_TX1, вывод B3;
- TX2, TI_TX2, вывод B5;
- TX3, TI_TX3, вывод B7;
- TX4, TI_TX4, вывод B9;
- RX1, TI_RX1, вывод M2;
- RX2, TI_RX2, вывод K2;
- RX3, TI_RX3, вывод H2;
- RX4, TI_RX4, вывод F2.

Для каждого канала показано восемь печатных элементов. Линии контролируемого импеданса, согласование и геометрия питания антенн задаются медью PCB.

## Проверка

PDF проверен как одностраничный векторный документ размером 6740 на 3800 пунктов. Проверены общий вид, матрица 145 межлистовых цепей, ВЧ узел, лист питания и последний лист. Выход за границы листа и пересечение рамок не обнаружены.

Комплект имеет статус предварительного EVT-выпуска. `Production authority = NOT_AUTHORIZED`. Для допуска к изготовлению остаются обязательными успешная нативная компиляция Altium, DRC платы, проверка импеданса у изготовителя, электромагнитное моделирование антенного узла и измерения первого образца.
