# RADAR D79 24 В. Полный комплект схем v2.2.6 RC8

Комплект содержит нативные исходники Altium, полную многостраничную PDF-схему, отдельный одностраничный мастер-лист, материалы проверки привязки контактных площадок и актуальную плату R9.

## Основные файлы

1. `01_Схема_Altium/RADAR_D79_24V_R9.PrjPcb` содержит основной проект из обзорного и 31 элементного листа.
2. `02_Мастер_лист_Altium/RADAR_D79_24V_R9_FULL_ELEMENT.PrjPcb` содержит отдельный проект полной элементной схемы на одном расширенном листе.
3. `03_PDF/RADAR_D79_R9_FULL_ELEMENT_MASTER.pdf` содержит одностраничную векторную схему для просмотра с увеличением.
4. `03_PDF/RADAR_D79_R9_full_schematic.pdf` содержит обзорный лист и 31 подробный лист.
5. `03_PDF/Антенный_узел_радара_D79_v0.8.0_R9.pdf` содержит отдельное представление круглого антенного узла.

## ВЧ тракт и антенны

На мастер-листе показан AWR2944P и восемь ВЧ каналов:

- TX1, TI_TX1, вывод B3;
- TX2, TI_TX2, вывод B5;
- TX3, TI_TX3, вывод B7;
- TX4, TI_TX4, вывод B9;
- RX1, TI_RX1, вывод M2;
- RX2, TI_RX2, вывод K2;
- RX3, TI_RX3, вывод H2;
- RX4, TI_RX4, вывод F2.

Для каждого канала показано восемь печатных элементов. Линии контролируемого импеданса, согласование и геометрия питания антенн задаются медью PCB и проверяются по материалам платы.

## Проверка

PDF проверен как одностраничный векторный документ размером 6740 на 2600 пунктов. Контрольные фрагменты ВЧ узла, листа питания и последнего листа находятся внутри своих рамок. Текстовые маркеры ВЧ каналов и заголовки крайних листов извлекаются из PDF.

Комплект имеет статус предварительного EVT-выпуска. `Production authority = NOT_AUTHORIZED`. Для допуска к изготовлению остаются обязательными успешная нативная компиляция Altium, DRC платы, проверка импеданса у изготовителя, электромагнитное моделирование антенного узла и измерения первого образца.
