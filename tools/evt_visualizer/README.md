# EVT ГСН Визуализатор 1.0.0

Программа принимает поток `TargetState V1` от платы `EVT_SYS_CARRIER` через USB-UART с логическими уровнями 3,3 В. Цели отображаются на индикаторе вида сверху, в таблице и в карточке выбранной цели. Программа может записывать одновременно CSV и исходный поток BIN, воспроизводить BIN и работать без прибора в демонстрационном режиме.

## Подключение

- J6.1 GND соединить с GND адаптера.
- J6.2 HOST_UART1_TX соединить с RX адаптера.
- J6.3 HOST_UART1_RX соединить с TX адаптера только при необходимости двустороннего обмена.
- Питание 3,3 В или 5 В с USB-UART адаптера к плате не подключать.
- Параметры порта: 921600 бод, 8 бит, без четности, 1 стоп-бит, без управления потоком.
- Плата получает питание отдельно через J1. USB-UART используется только для данных и общей земли.
- Адаптеры RS-232 и RS-485 не подходят.

Запасной канал использует J6.4 GND, J6.5 HOST_UART2_TX и J6.6 HOST_UART2_RX.

## Запуск исходного кода

```powershell
python -m pip install -r tools/evt_visualizer/requirements.txt
python -m tools.evt_visualizer
```

## Проверка без прибора

Нажмите кнопку `Демо`. Для проверки декодирования записи нажмите `Открыть BIN` и выберите двоичный файл с последовательными пакетами по 200 байт.

## Работа с прибором

1. При снятом питании соедините J6 с USB-UART по схеме выше.
2. Подключите USB-UART к компьютеру и установите официальный драйвер производителя адаптера, если Windows не сделала это автоматически.
3. Подайте штатное питание 12 В на J1, соблюдая методику первого включения.
4. Запустите `EVT_GSN_Visualizer.exe`, нажмите `Обновить`, выберите появившийся COM-порт и нажмите `Подключить`.
5. Для сохранения результата нажмите `Запись`. Программа создаст CSV для анализа и BIN для повторного воспроизведения.

Полная схема стенда, перечень оборудования, критерии остановки и поиск неисправностей приведены в DOCX и PDF из папки `03_Инструкции` выпускного архива.

## Сборка EXE

Установите `pyserial` и `PyInstaller`, затем выполните `tools/evt_visualizer/build_windows.ps1`. Готовый файл не требует установленного Python.
