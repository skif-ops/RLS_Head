# EVT ГСН цифровой двойник для Windows

Программа формирует поток TargetState V1 для нескольких настраиваемых летающих объектов и передает его визуализатору по локальному TCP-соединению.

Для каждого объекта настраиваются ID, имя, включение, ЭПР, скорость, начальная дальность, азимут, угол места, курс, вертикальная скорость и маневр. ЭПР участвует в упрощенной модели SNR по зависимости `10 log10(ЭПР / 0,01)` и в расчете качества сопровождения. Эта модель предназначена для проверки программного тракта и не заменяет измерение реальной радиолокационной характеристики.

По умолчанию двойник слушает `127.0.0.1:9750`. Визуализатор подключается кнопкой `Подключить к двойнику` и принимает обычные 200-байтовые пакеты TargetState V1. Двойник не формирует управляющих команд внешнему оборудованию.
