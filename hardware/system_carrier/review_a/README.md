The real Review A package is generated by the CAD CI job from the exact ERC-clean System Carrier schematic produced for the same commit.

The package contains:

- `EVT_SYS_CARRIER.kicad_sch`;
- `erc.json`;
- `PINMAP_SYS_001.csv`;
- `BOM_SYS_CARRIER_003.csv`;
- `manifest.json`;
- `audit_details.json`;
- `result.json`;
- `package_summary.json`.

The package is validated by `tools.carrier_review_a` with:

- `synthetic_fixture = false`;
- `evidence_level = CAD_REVIEW`;
- ERC errors = 0;
- ERC warnings = 0;
- all required audits = PASS.

The Review A package is uploaded as the CI artifact `system-carrier-review-a`.

Closing Review A is an electrical schematic gate only. It does not by itself authorize production or make the native Altium PCB implementation authoritative. The next PCB gate is the Altium import/equivalence gate defined in `docs/CAD_POLICY_ALTIUM.md`.
