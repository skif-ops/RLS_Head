# A10 planning baseline

This directory preserves the pre-A10 native geometry used by the signal-route planner and its offline validators. The files were copied from `connection_audit` at commit `ab00e8fa4652b1c2ef5c641ff06d39c1a30235e1` before the final routed board export replaced that directory with post-route evidence.

The baseline is read-only planning input. Current canonical connectivity evidence remains under `routing/connection_audit`.
