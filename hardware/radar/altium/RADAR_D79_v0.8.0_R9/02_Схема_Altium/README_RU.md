# Полная электрическая принципиальная схема RADAR D79 R9

Основной файл проекта: `RADAR_D79_24V_R9.PrjPcb`.

Общая электрическая принципиальная схема выполнена как единый проект из 32 листов: обзорный лист 00 формата A1 и 31 детальный лист. На листе 00 показаны основные функциональные узлы, направления сигналов и питания, а также ссылки на детальные листы 01-31. Детальные листы сохраняют полный состав компонентов и цепей. Связь между листами задана именами цепей.

Для просмотра всей схемы в Altium Designer откройте основной файл проекта, затем раздел `Source Documents`. Единая 32-страничная версия для чтения и печати находится в файле `Native_Outputs_R9/Documentation/RADAR_D79_R9_full_schematic.pdf`. Отдельная обзорная схема находится в файле `Native_Outputs_R9/Documentation/RADAR_D79_R9_system_overview_A1.pdf`.

Состав схемы охватывает:

- вход питания 24 В, защиту и преобразователи;
- микроконтроллер и его питание;
- два UART 3,3 В;
- внешний GNSS;
- IMU;
- CAN FD;
- сервисный USB и загрузочные цепи;
- AWR2944P, QSPI и служебные интерфейсы;
- формирование и фильтрацию линий питания радара;
- сервис VPP.

Результаты автоматической проверки находятся в папке `Проверка`. Перед выдачей производственного допуска необходимо закрыть 12 замечаний Altium Validate, перечисленных в `R9_schematic_receipt.md`.
