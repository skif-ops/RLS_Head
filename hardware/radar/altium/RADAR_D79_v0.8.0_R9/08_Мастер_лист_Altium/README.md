# Полная элементная схема RADAR D79 R9

В папке находится отдельный проект Altium с одним расширенным листом. Он предназначен для подробной проверки электрической схемы и подготовки новой трассировки. Проект не входит в компиляцию основного проекта, чтобы не дублировать обозначения компонентов.

Состав:

- `RADAR_D79_24V_R9_FULL_ELEMENT.PrjPcb`, отдельный проект мастер-листа;
- `00_FULL_ELEMENT_SCHEMATIC.SchDoc`, нативный бинарный лист Altium;
- `RADAR_D79_R9_FULL_ELEMENT_MASTER.pdf`, одностраничная векторная PDF-версия для просмотра и печати.
- `R9_master_inter_sheet_connectivity.csv`, перечень 145 межлистовых цепей и номеров исходных листов;
- `R9_pad_binding.csv`, таблица 1 408 контактов компонентов для проверки и повторной трассировки. Из них 1 181 контакт имеет назначенную цепь, 227 контактов отмечены как неподключённые.

Нативный мастер-лист содержит 3 497 скопированных примитивов 31 исходного листа. Сохранены компоненты, номера и имена выводов, локальные проводники, метки цепей, обозначения и номиналы. Дополнительно на лист добавлены 145 реальных объектов `Wire` и `Net Label` Altium. Каждый межлистовой проводник имеет точное имя цепи и метки номеров тех листов, на которых эта цепь используется.

Для повторной трассировки следует применять комплект совместно:

1. По `00_FULL_ELEMENT_SCHEMATIC.SchDoc` проверяют состав узлов, локальные проводники и межлистовые цепи.
2. По `R9_master_inter_sheet_connectivity.csv` проверяют распространение каждой цепи по листам 01...31.
3. По `R9_pad_binding.csv` восстанавливают точное соответствие `Designator`, `Pad`, `Net` для 1 181 подключённого контакта и контролируют 227 неподключённых контактов.
4. По исходным 31 файлам `SchDoc` выполняют детальную проверку отдельных узлов.
5. По нативному `PcbDoc` выполняют размещение, назначение классов цепей, правила, трассировку и DRC.

В левой верхней ячейке показаны ВЧ тракт AWR2944P и печатные антенные каналы TX1...TX4, RX1...RX4. Для каждого канала показано восемь печатных элементов и приведена привязка к выводу микросхемы. Линии контролируемого импеданса, согласующие участки и геометрия питания антенн задаются медным рисунком платы.

Остальные 31 ячейка содержат полные элементные листы исходного проекта. В нижней части PDF приведена матрица межлистовых соединений с точными именами цепей, количеством привязанных контактов и указанием листов. PDF сохраняет векторные линии и текст, поэтому обозначения следует проверять с увеличением.

`Production authority = NOT_AUTHORIZED`. Мастер-лист является конструкторским представлением и не заменяет DRC, проверку импеданса, электромагнитное моделирование и стендовые измерения.
