# Measurement execution packs\n\nThese packs prepare the file structure for real measurement campaigns.\n\nThey are templates only and never count as project evidence.\n\nSupported pack kinds:\n\n- `m300`\n- `reference_range`\n- `hil_r2_bench`\n- `sys_err`\n- `physical_antenna`\n- `evm_profile`\n\nGenerate a pack:\n\n```bash\npython -m tools.measurement_pack generate \\n  --kind m300 \\n  --output-dir work/m300\n```\n\nValidate its structure:\n\n```bash\npython -m tools.measurement_pack validate work/m300\n```\n\nA valid template returns `TEMPLATE_READY`.\n\nEvery generated pack includes:\n\n- `pack_manifest.json` with `template_only: true`;\n- a result-oriented `evidence_claim.template.json`;\n- domain-specific CSV/manifest skeletons;\n- README instructions.\n\nAll `<FILL...>` placeholders must be replaced after data collection.\nSHA-256 values are intentionally not pre-generated for measured data.\n\nAfter real data collection:\n\n1. populate the domain manifest/CSV;\n2. compute hashes;\n3. run the domain validator;\n4. create the result JSON;\n5. fill the evidence claim;\n6. run `tools.evidence_promote`;\n7. review the candidate project evidence manifest before merge.\n\nA pack itself cannot close any measured evidence item.\n
