# D1 EM solver provenance\n\nThis evidence contract verifies that D1 antenna-map evidence originates from a concrete solver/model/material/export package.\n\nIt does not encode or freeze production Tx/Rx physical coordinates.\n\n## Manifest\n\n`ANT-D1-EM-MANIFEST-001` requires:\n\n- solver name/version;\n- model id/revision;\n- model input artifact;\n- material-definition artifact;\n- raw solver/far-field export artifact;\n- machine-readable antenna map artifact;\n- SHA-256 for every artifact.\n\nThe antenna map is then validated by the existing D1 map validator at the required 76 / 78.5 / 81 GHz groups.\n\n## Evidence status\n\n- synthetic fixture -> `TEST_READY`\n- real `SIMULATED_EM`, `SIMULATED_EM_CORRELATED` or `MEASURED_EM` package -> `DATA_READY`\n- structurally valid but unsupported evidence level -> `HOLD`\n- incomplete map -> `FAIL`\n- hash/schema/path failure -> `INVALID`\n\nRun:\n\n```bash\npython -m tools.ant_em_evidence \\n  --manifest d1_em_manifest.json \\n  --map-config config/d1_map_validation_evt.json \\n  --repository-root . \\n  --output d1_em_evidence.json\n```\n\nA `DATA_READY` result may then be promoted to `ANT_D1_EM_REAL` through the project evidence-promotion guard.\n
