# AWR2944P observation firmware

This directory contains the project-owned observation layer for the TI AWR2944P. It is integrated over the official TI TDM object-detection demo during the build. TI SDK sources are not copied into the repository.

The firmware accepts the Cartesian point cloud generated by the TI data path, derives range, radial velocity, azimuth and elevation, associates one observed target, and transmits a 64-byte CAN FD measurement frame. It does not calculate interception, lead, convergence course, movement commands, actuator commands or external-control commands.

The MCAN contract is:

- standard ID `0x320`, AWR2944P to carrier;
- standard ID `0x321`, carrier to AWR2944P;
- CAN FD with bit-rate switching;
- 500 kbit/s arbitration phase;
- 2.5 Mbit/s data phase;
- 64-byte frames;
- little-endian fields and CRC32C as implemented by `radar_link.c`.

Service requests contain a one-byte operation at payload offset 0 and a nonzero little-endian request ID at offset 4. All remaining bytes of the 16-byte service payload are zero. Supported operations are start observation output, stop observation output and reset communication statistics. These operations do not start or stop the RF sensor and do not control motion.

## Tool versions verified

- MMWAVE-MCUPLUS-SDK 04.07.02.01
- MCU+ SDK AWR2x44P 10.02.00.04
- mmWave DFP 02.04.18.01
- SysConfig 1.23.0
- TI ARM Clang 4.0.2 LTS
- TI C6000 compiler 8.3.13
- Code Composer Studio 20.1.0

Run `tools/build_target.ps1` from PowerShell. The script creates a disposable build tree below the repository `.work` directory, applies the observation overlay, compiles the R5F and C66x images, and produces `awr2x44P_mmw_demoTDM.appimage`. The high-security `.appimage.hs` additionally requires an OpenSSL executable compatible with the TI signing script.

The current limits, including 350 m maximum admission range and elevation admission of plus or minus 22 degrees, are configuration gates, not verified performance claims. RCS and uncertainty fields remain invalid until bench calibration supplies traceable conversion and error estimates.
